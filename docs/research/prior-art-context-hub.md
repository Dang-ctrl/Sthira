# Everyone builds context layers, nobody shares one

As of mid-October 2026, no one ships the full "super tool" described here, and no one has announced it: a user-owned, local-first hub on open models and open standards that holds what is settled for a person, is fed by every tool, is read by every assistant, and warns when new work contradicts past decisions. The components all exist, scattered across roughly four camps. All six big platforms launched a persistent personal-context layer in 2026, but **each one is scoped to its own ecosystem and runs on proprietary models**. Enterprise vendors (Glean, Atlassian, Microsoft) sell permission-aware context graphs over MCP, but they are tenant-bound and none treats a decision as a first-class object. Decision-first products (Sentra, Uvi, Lockstep, Town) are seed-stage team SaaS. Open-source projects cover capture (Screenpipe), plain-file memory (Basic Memory, OpenClaw) and temporal fact invalidation (Graphiti), but none models "settled versus open" across a whole life. The plumbing is effectively solved: MCP is now under Linux Foundation governance and about every major assistant speaks it. What remains open is the semantics, meaning a portable, open schema for decisions, reasons, supersession and open questions, plus contradiction warnings that run locally. Analysts say plainly that "no lab has shipped a cross-vendor export standard" ([Activant](https://www.activantcapital.com/research/the-memory-moat)). Platform incentives run the other way, so the cross-vendor, user-owned version is unlikely to come from a platform. Sixty years of lifelogging and semantic-desktop failures show where such projects die: on retrieval quality, resource cost, privacy backlash and vendor death, not on storage. For a hackathon project, the implication is to build the smallest trustworthy version of the semantic layer (an open decision schema with a local contradiction check, served over MCP) rather than another capture or memory engine.

## Six platforms shipped personal context in 2026, each behind its own wall

Every major platform moved in 2026, and they converged on "one memory per vendor, shared across that vendor's surfaces." **Apple** announced Siri AI on June 8, 2026. It searches messages, email and photos, and the Spotlight index and App Toolbox "work entirely on device." Third-party apps contribute context only by integrating with Spotlight, and Siri is the only consumer of that context ([Apple Newsroom](https://www.apple.com/newsroom/2026/06/apple-introduces-siri-ai-a-profoundly-more-capable-and-personal-assistant/)). Apple comes closest to local-first but has the weakest explicit memory model. **Google** launched Personal Intelligence across Gmail, Photos, Search and YouTube in January ([Google](https://blog.google/innovation-and-ai/products/gemini-app/personal-intelligence/)). In October it announced an enterprise Gemini agent with "a single set of memories, context, and one personalization graph" and four memory types: current task, document knowledge, learned procedures, and a record of past actions ([9to5Google](https://9to5google.com/2026/10/08/gemini-agent-google-cloud/)). **Microsoft's** Work IQ reached GA in June with "personal memory" and MCP, A2A and REST interfaces, but "data, context, and insights stay within the Microsoft 365 tenant trust boundary" ([Microsoft 365 blog](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/02/announcing-the-new-work-iq-apis/)). Its one fully local lifelog, Recall, is still contested ([GeekWire](https://www.geekwire.com/2026/one-year-after-its-rocky-launch-microsofts-windows-recall-still-raises-security-red-flags/)).

**OpenAI's** "Dreaming V3" replaced curated saved memories with background synthesis that "revises existing memories as circumstances change." Its audit trail is weak: the summary page "may not show everything ChatGPT remembers," and memories derived from a chat survive deletion of that chat ([TechTimes](https://www.techtimes.com/articles/317840/20260605/chatgpt-memory-dreaming-update-openai-rewrites-personalization-engine-limits-audit-trail.htm)). Newsletter coverage of DevDay 2026, not verified against OpenAI's own pages, describes always-on "Dots" agents that inherit ChatGPT memory and frames the event as ChatGPT "becoming an AI operating system" ([The Neuron](https://www.theneuron.ai/news/openai-devday-2026-chatgpt-is-becoming-an-ai-operating-system/)). **Anthropic** unified chat and Cowork memory into "a single memory" in August, editable by topic and on by default for consumer plans ([TechCrunch](https://techcrunch.com/2026/08/25/claude-cowork-finally-remembers-what-you-told-the-app-in-chat/)). Earlier, in March, it shipped a memory importer that works by pasting a summary the rival assistant writes ([MacRumors](https://www.macrumors.com/2026/03/02/anthropic-memory-import-tool/)). **Meta** bought Limitless (formerly Rewind) in December 2025 and shut off its desktop capture ([CNBC](https://www.cnbc.com/2025/12/05/meta-limitless-ai-wearable.html)). In September 2026 it released Muse, a personal agent that "gets to know you," bound for its glasses ([Meta](https://www.meta.com/blog/muse-personal-agent-ai-glasses/)).

Two findings hold across all six. First, **none models decisions with reasons, open questions, or contradiction warnings as first-class objects**. The nearest primitives are OpenAI's time-aware revision (stale-fact supersession, not decision tracking) and Google's "record of past actions." Second, openness only flows inward. Each platform uses MCP and connectors to pull other tools' data in, and offers importers to pull rivals' memories in, but **none exposes its accumulated memory for a rival assistant to read**. One vendor-side commentator summarizes it bluntly: "each platform maintains its own memory independently; none of them reads the others" ([MemoryLake](https://www.memorylake.ai/en/blogs/is-ai-memory-a-feature-or-lock-in)). None uses open-weight models for these features.

## Enterprise context graphs commoditized while decision ledgers stayed at seed stage

In enterprise software, the incumbent design has settled into a permission-aware graph plus an MCP server, with memory layered on top. Atlassian opened Teamwork Graph to third-party agents at Team '26 and claims 44% more accurate answers using 48% fewer tokens, a vendor benchmark ([SiliconANGLE](https://siliconangle.com/2026/05/06/atlassian-opens-teamwork-graph-pushes-rovo-agentic-execution-team-26/)). In June, Glean let MCP hosts including ChatGPT, Claude and Cursor **write, update and delete memories "with full source provenance"** ([Glean release notes](https://docs.glean.com/release-notes/releases/2026-06-03-june-release)), and from October 17 its activity-based memory is billed in credits ([Glean](https://docs.glean.com/release-notes/releases/2026-08-18-august-release)). Glean is the clearest example of "one store consulted by every assistant" in production. It is organizational, cloud or VPC hosted, and its memory holds preferences and activity, not settled decisions. Its contradiction handling reportedly shows conflicting sources side by side and leaves the user to decide ([Fini](https://www.usefini.com/guides/ai-knowledge-base-conflicting-answers)). Unblocked claims automatic conflict resolution by recency and authority, but it resolves conflicts silently rather than warning ([Unblocked](https://getunblocked.com/blog/unblocked-vs-glean/)).

Decisions as first-class objects appear only in small companies. Sentra records each decision with date, author and later reversals, links a new decision to the one it supersedes, and serves this to agents over MCP, but it describes no contradiction detection beyond supersession ([Sentra](https://www.sentra.app/articles/decision-log)). Uvi, with a $7.5M seed in October 2026, builds a "Decision Graph" linking decisions to owners, triggers, blockers and evidence for R&D teams ([Blocks & Files](https://www.blocksandfiles.com/ai-ml/2026/10/12/uvi-gives-ai-agents-enterprise-context/5302514)). Lockstep drafts decisions from Slack and tickets and says it "flags conflicting work early" ([Lockstep](https://www.getlockstep.dev/blog/best-decision-log-tools-product-engineering)). Town's Leadership Decision Log, which earlier research found but the latest pass could not re-locate, flags reversals across meetings for leadership teams ([Town](https://www.town.com/routines/leadership-decision-log)). The investment thesis exists: Foundation Capital's "context graphs" and "decision traces" essay argued early capture of decision traces would become a moat ([Foundation Capital](https://foundationcapital.com/ideas/context-graphs-ais-trillion-dollar-opportunity)). Money mostly goes elsewhere, though. Engram raised $98M for learned, parametric organizational memory with no decision records ([CNBC](https://www.cnbc.com/2026/06/23/ai-memory-startup-focused-on-cutting-token-costs-raises-98-million.html)), and Granola reached $1.5B as a notetaker expanding into an enterprise app ([TechCrunch](https://techcrunch.com/2026/03/25/granola-raises-125m-hits-1-5b-valuation-as-it-expands-from-meeting-notetaker-to-enterprise-ai-app/)).

Integration hubs are pipes plus policy, not shared state. Zapier MCP reaches 9,000+ apps with allowlists and approval logs ([StackOne](https://www.stackone.com/blog/best-mcp-gateways/)). SAP valued n8n at $5.2B ([Bloomberg](https://www.bloomberg.com/news/articles/2026-05-12/sap-invests-in-ai-automation-startup-n8n-at-5-2-billion-value)), and Workday agreed to buy Pipedream ([Pipedream](https://pipedream.com/blog/pipedream-to-be-acquired-by-workday/)). Docker, MetaMCP, IBM ContextForge and Kong federate MCP servers. A search for shared-memory features in MCP or A2A gateways returned nothing ([Scalekit](https://www.scalekit.com/blog/best-open-source-mcp-gateways)). The governance question for the interface is also settled: OpenAI, Anthropic and Block placed MCP, AGENTS.md and goose under the Linux Foundation's Agentic AI Foundation in December 2025 ([Anthropic](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)). MCP SDK downloads reportedly reached about **97M per month** by March 2026 ([Nordic APIs](https://nordicapis.com/10-interesting-mcp-statistics/)). In practice, "consulted by every assistant" is now achieved by exposing one MCP server.

## Open source has every piece of the vision but no assembly

The open-source landscape covers each layer of the vision separately. The table maps the vision's requirements against the strongest open-source and commercial coverage found.

| Vision requirement | Best existing coverage | Status |
|---|---|---|
| Fed by every tool | Screenpipe (local screen and audio, MCP), Zapier/Composio connectors, cross-agent session parsers (31 providers) | Commoditized |
| Consulted by every assistant | MCP; Glean memory writeback; Basic Memory MCP | Commoditized |
| User-owned, local-first storage | Basic Memory (Markdown + SQLite), OpenClaw (plain files), Anytype/any-sync | Available |
| Open models | Ollama-based stacks (Supermemory local, Khoj) | Available, quality-limited |
| History of what was true | Graphiti bi-temporal edges; Sentra supersession | Primitive exists |
| Decisions with reasons, open questions, settled status | Sentra, Uvi (team SaaS); projectmem, smm-sync (per repo, coding only) | Fragmented, no personal scope |
| Warns when new work contradicts past decisions | smm-sync (hosted judge, inactive), Town (cloud, meetings), Lockstep | Nearly absent; none local and cross-source |
| Open, portable schema for all of the above | None; DTI says "we aren't there yet" | Absent |

Traction follows usefulness, not storage. OpenClaw, a personal agent hub that keeps memory, conversations and skills as plain Markdown and YAML, passed roughly **370k GitHub stars** by mid-2026, though counts are approximate and security concerns follow it ([Towards AI](https://pub.towardsai.net/what-is-openclaw-the-350-000-star-ai-agent-785134a0706f); [DEV](https://dev.to/jahanzaibai/what-is-openclaw-everything-you-need-to-know-about-the-worlds-most-starred-ai-agent-3l10)). Basic Memory turns Markdown files into entities and relations readable over MCP and editable in Obsidian ([Basic Memory docs](https://docs.basicmemory.com/technical/technical-information)), and it already imports Claude and ChatGPT exports ([GitHub](https://github.com/basicmachines-co/basic-memory)). Graphiti offers the closest semantics to "settled truth with history": a contradicted fact is invalidated with timestamps rather than deleted, with an LLM judging the contradiction ([Graphiti docs](https://mintlify.com/getzep/graphiti/concepts/temporal-model)). Coding-agent memory is crowded, with claude-mem at **101k stars** and a `decision` observation type ([claude-mem](https://github.com/thedotmack/claude-mem)). The closest match to the record-and-check loop, smm-sync/Axiom Hub, compares new decisions against stored ones with embeddings plus a Claude Haiku judge, but it covers coding only and is listed as inactive ([Glama](https://glama.ai/mcp/servers/varunajaytawde28-design/smm-sync)). projectmem marks decisions stale when the files they cite change, but it works per repository and does not detect contradictions between decisions ([projectmem](https://github.com/riponcm/projectmem)).

Self-hosted personal AI is also fragile as a business. Khoj, at about 37k stars, reportedly sunset its hosted cloud in April 2026 ([promptquorum](https://www.promptquorum.com/power-local-llm/khoj-ai-second-brain-review)). The Reor local note app was archived in March 2026 ([GitHub](https://github.com/reorproject/reor)). Mem0 reportedly removed its local OpenMemory server in July 2026 ([Coworker](https://coworker.ai/blog/best-mcp-memory-servers)), and Screenpipe moved from MIT to source-available with telemetry on by default ([ExplainX](https://www.explainx.ai/blog/screenpipe-yc-s26-local-work-memory-agents-july-2026)). The pattern is "local and open" drifting toward hosted and closed under commercial pressure. This makes a credibly open project a differentiator, not merely a stance.

## Sixty years of personal memory hubs failed on meaning, not storage

The historical record shows a consistent split. Ambitious "hold everything about a person" systems failed, and narrow features that platforms absorbed succeeded. Gordon Bell's MyLifeBits at Microsoft Research hit retrieval first: "When I started, I couldn't find anything!" ([Berkeley iSchool](https://courses.ischool.berkeley.edu/i202/f11/node/220.html)). Bell later concluded it "wasn't something that was bringing a lot of value to my life" and that smartphones now do most of the job ([Computerworld](https://www.computerworld.com/article/1663309/lifelogging-is-dead-for-now.html)). The EU-funded NEPOMUK semantic desktop failed on heavy formal semantics. RDF "proved to be oversized," initial indexing hogged RAM and CPU, users disabled it, and KDE replaced it with Baloo, which kept the code and dropped the RDF ([xmodulo](https://www.xmodulo.com/kde-semantic-desktop-nepomuk-baloo.html); [Vishesh Handa](https://vhanda.in/blog/2015/03/kde-and-the-semantic-desktop)). Google Desktop died in 2011 because data moved to the web and operating systems built local search in ([Wikipedia](https://en.wikipedia.org/wiki/Google_Desktop)). Evernote, the original "remember everything" product, lost to Keep, Notion and OS note apps and had "been unprofitable for years" by its 2023 sale ([TechCrunch](https://techcrunch.com/?p=2491541)).

The AI-era failures repeat the same causes in new forms. Microsoft Recall's first build stored snapshots in a plaintext SQLite database readable by non-admin accounts, forcing a redesign as opt-in and gated by Windows Hello ([SC Magazine](https://scmagazine.com/news/microsofts-ai-recall-feature-postponed-to-address-security-concerns)). Signal, Brave and AdGuard then blocked it ([Engadget](https://engadget.com/ai/brave-and-adguard-now-block-microsoft-recall-by-default-152601475.html)). Humane raised more than $230M and was sold to HP for $116M after its servers shut down ([TechRadar](https://www.techradar.com/computing/artificial-intelligence/with-the-humane-ai-pin-now-dead-what-does-the-rabbit-r1-need-to-do-to-survive)). Rewind users had to export their data before capture was switched off after the Meta deal ([9to5Mac](https://9to5mac.com/2025/12/05/rewind-limitless-meta-acquisition/)). Solid, Tim Berners-Lee's personal data pod project, still lacks a consumer market, with about 15 mostly experimental hosted pod services ([OpenReplay](https://blog.openreplay.com/es/estado-web-descentralizada-2026/)). Academic work on personal knowledge graphs still calls the field "early stage" and says its very definition is "one of the fundamental challenges" ([Skjæveland, Balog et al.](https://arxiv.org/abs/2304.09572)).

Four lessons follow. **Capture is easy and meaning is hard**, so a hub focused on curated settled facts targets the right bottleneck. **Heavy schemas kill adoption**, and plain files with a light schema are winning now. **Total capture provokes backlash and blocking**, which argues for explicit, user-approved writes. **Vendor death strands memory**, which is the strongest argument for local-first storage and open formats. The successes (Spotlight, Baloo, phone photo search) succeeded by being small, fast and built into something people already used daily.

## Platforms will deepen silos while the neutral layer stays open

The direction of travel is clear. Each platform is racing to become the user's "operating layer for AI" ([Forbes](https://www.forbes.com/sites/janakirammsv/2026/05/21/google-io-2026-turned-gemini-into-an-agent-platform/)), with capture moving into wearables and the home: OpenAI's rumored 2027 device, Meta's glasses, Apple TV personal context ([MacRumors](https://www.macrumors.com/2026/02/20/jony-ive-openai-smart-speaker-2027/); [MacRumors](https://www.macrumors.com/2026/10/13/apple-tv-finally-gaining-apple-intelligence/)). Within one to three years, every major vendor will likely offer a single persistent memory across its own devices. That vendor will be unlikely to let a competitor read it, because accumulated memory is "one of the last real switching costs" ([Activant](https://www.activantcapital.com/research/the-memory-moat)) and memory moats are "far harder to replicate or port" than model advantages ([arXiv 2508.05867](https://arxiv.org/html/2508.05867v1)). Vendors also lack the raw material for a truly cross-tool view. Claude Code's memory does not carry over to Codex, Cursor or ChatGPT ([MemoryPlugin](https://blog.memoryplugin.com/claude-code-memory/)).

The counter-thesis is just as concrete. Activant retracted its own "context moat" view in August 2026, arguing that memory is moving into middleware that writes to customer-owned stores and that value goes to "whoever controls the write path." It named one condition that would break this: a lab shipping fully portable cross-vendor memory ([Activant](https://www.activantcapital.com/research/the-memory-moat)). Regulation could push export but probably not live sharing. GDPR Article 20 already requires machine-readable portability of data a user provided ([GDPR Art. 20](https://gdpr-info.eu/art-20-gdpr/)). The Data Transfer Initiative concluded in March 2026 that a shared memory schema is not there yet ([CDT](https://cdt.org/insights/dont-let-perfect-be-the-enemy-of-portable/)).

Weighing these, the likely builders of a neutral cross-vendor hub fall into three groups. Open-source communities around plain-file memory and MCP (Basic Memory, OpenClaw, Graphiti) are each one feature away from parts of it. Startups pitching user-owned context, such as YC S2026's Egoist Machines, "where your personal context belongs to you," have no product detail yet ([YC](https://www.ycombinator.com/companies/industry/ai-assistant)). The third is the AAIF standards process, if it takes up a memory schema the way it took up AGENTS.md. Enterprise vendors such as Glean are the most likely to ship decision objects and contradiction checks first, but for organizations, in the cloud. The single largest risk to a neutral project is that one lab ships both decision tracking and real export. OpenAI's supersession and Google's action history are the building blocks, so that could happen quickly if a vendor chooses to.

## Context is the bottleneck, which makes curation more valuable than recall

The evidence that context, not raw model capability, limits AI usefulness is strong. Chroma tested 18 models and found that "model performance consistently degrades with increasing input length," with distractors hurting more as context grows ([Chroma](https://www.trychroma.com/research/context-rot)). The NeurIPS 2025 MAST study of 1,600+ multi-agent traces attributed failures "primarily" to system design and inter-agent misalignment rather than model limits ([arXiv 2503.13657](https://arxiv.org/html/2503.13657v3)). Developers want grounding. In Stack Overflow's 2025 survey, 84% use or plan to use AI tools, but **46% distrust the accuracy of AI output**, up from 31% ([Stack Overflow](https://stackoverflow.co/company/press/archive/stack-overflow-2025-developer-survey/)). A 2026 study found coding agents follow a stale convention file even when it prescribes worse code, so **a stale context file can cost more than none** ([arXiv 2608.16630](https://arxiv.org/abs/2608.16630)). Taken together, these favor a small, curated, provenance-tagged store of what is settled over a larger archive. They also show why supersession is a core feature, not an extra.

The evidence against is also substantial. Memory is an attack surface. Sleeper memory-poisoning attacks inserted poisoned memories up to 99.8% of the time and, once those memories were retrieved, caused attacker-intended actions in 60–89% of evaluations ([arXiv 2605.15338](https://arxiv.org/pdf/2605.15338)). A preliminary CSA note reports a single crafted email corrupting MEMORY.md-style files with 87.5% success, while three tested defenses each missed over 90% of attacks ([CSA Labs](https://labs.cloudsecurityalliance.org/research/csa-research-note-memghost-agent-memory-poisoning-20260723-c/)). A hub fed by email and meetings and read by every assistant concentrates that risk. Extraction quality is the second risk: an audit of 10,134 Mem0 entries found 97.8% junk, including one invented preference stored 808 times ([mem0 #4573](https://github.com/mem0ai/mem0/issues/4573)). Benchmarks show conflict resolution is the weakest capability of every memory system tested, at **at most 7%** on multi-hop conflict tasks ([MemoryAgentBench](https://arxiv.org/html/2507.05257v3)). The third is commercial: Gartner expects over 40% of agentic AI projects to be cancelled by 2027 ([Gartner](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027)), and platforms bundle native memory for free. No survey found measures how many people use two or more assistants or whether they would centralize context, so mainstream demand for the cross-vendor case is unproven.

Developers benefit first and most. Among developers using agents, 82% use ChatGPT, 68% GitHub Copilot, 47% Gemini and 41% Claude Code ([Stack Overflow](https://stackoverflow.co/company/press/archive/stack-overflow-2025-developer-survey/)), and AGENTS.md is reportedly in 60,000+ projects ([OpenAI](https://openai.com/blog/agentic-ai-foundation)). That is a hand-maintained, per-repository version of this hub already in use. Small teams come next, since decision and meeting context is where Granola and Glean show value. Privacy-constrained professionals and price-sensitive users benefit from local, open-model operation. India illustrates the second group: 100M weekly ChatGPT users, the largest student base, and assistants competing through free promotions ([TechCrunch](https://www.techcrunch.com/2026/02/15/india-has-100m-weekly-active-chatgpt-users-sam-altman-says/)). The claim that portability matters there is reasoned, not measured.

## The open gap is a schema for settled truth plus a local check

The remaining gap is precise. It is not ingestion, MCP serving, local storage or search, all of which are commodities. It is the intersection of four properties no shipped system combines. The first is **a personal, cross-vendor scope** that treats AI chats, agent sessions and meetings as sources, which enterprise layers do not. The second is **explicit status semantics**: decision, rationale, rejected alternatives, open question, settled, superseded, each with provenance and validity dates. The third is **proactive, cited contradiction warnings running on a local open-weight model**, rather than silent resolution or side-by-side display. The fourth is **an open, documented schema** other tools can write and read, which no standards body has produced. Each of the nearest projects (Sentra, Glean, smm-sync, projectmem, Graphiti, Basic Memory) lacks at least two of these.

For an open-source project started at a hackathon, this has four implications. First, the vision as stated, fed by every tool and including voice, email, browser and databases, is the scope at which MyLifeBits, NEPOMUK and Recall failed. The defensible core is the semantic layer, not the capture surface. Second, the most durable contribution is the **open schema plus a published eval**, because that is what platforms will not provide and what could let Basic Memory, OpenClaw or Meetily emit compatible records rather than compete. Third, trust properties are the product: an OSI licence, no telemetry, write gating with user confirmation, and reproducible accuracy claims. Rivals have lost credibility on exactly these, and the poisoning research requires them. Fourth, novelty claims must be narrow. "First to detect decision contradictions" is false given smm-sync, Town and Lockstep. "First open, local, cross-vendor ledger of settled decisions" is defensible today.

## Conclusion

The question has shifted from whether the super tool exists to who will own the meaning of a person's context. The integration problem that sank earlier personal-hub attempts is now solved by MCP under neutral governance, and the platforms are competing to own the write path inside their own walls. What remains unclaimed is a vocabulary for "settled": a shared definition of a decision, its reasons, and when it stopped holding. History suggests vocabularies outlast the products that introduce them. AGENTS.md spread to tens of thousands of projects because it was a simple convention, not a platform.

That points to an unusual strategy for a hackathon project: aim to be the reference implementation of a format, not a destination app. The platforms' incentive to keep memory closed is the main reason the opening exists. The main reason it could close is a lab shipping portable memory with decision semantics, and the open-weight judge quality that would make a local alternative credible is still unmeasured. A small, honest benchmark of whether a 4–8B model can reliably detect "I changed my mind" would therefore be worth more than any feature list, both as evidence and as a way to recruit contributors.
